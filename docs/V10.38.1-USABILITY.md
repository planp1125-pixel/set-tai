# Set-Tai v10.38.1 — Usability branch

This branch is separate from main (v10.38). Do not merge without owner approval.

## Changes
- Explore tab with searchable entry points for Shows, Characters, Studio, Chat, Brain, Skills, Diary, World, Wallpaper and Permissions.
- Home now starts with quick access to Shows, Explore and Characters; the existing controls remain below.
- Settings exposes System / Light / Dark using the existing ThemeSkin preference.
- First-install-only, skippable welcome; upgrades do not receive a new onboarding prompt.
- Version 10.38.1, versionCode 77.

## Deliberate non-changes
- No Google login, Supabase or database migration.
- No animation/physics/show-engine modifications.
- Existing preferences, characters, shows, permissions and app ID remain unchanged.
- No automatic permission requests from onboarding.

## Validation before release
1. Run Gradle unit tests and compile the full flavor.
2. Fresh install: welcome appears once; skip, Explore and Choose character work.
3. Upgrade from v10.38: no welcome; all previous settings remain.
4. Test Explore search, no results, and every destination.
5. Test light, dark and system appearance on Home, Explore, Settings and secondary screens.
6. Test overlay permission flow, start/stop, background operation, shows and gestures.
7. Test accessibility with screen reader, large text, keyboard and landscape.
8. Inspect GitHub Actions logs; only then build and install an APK.

## Known limitation
ThemeSkin currently restyles view trees rather than using a fully semantic theme architecture; visual QA is necessary. Existing Home and Settings advanced controls remain lengthy. This is a navigation-first improvement, not a complete UI rewrite.
